# 灵镜 AI 音响 — 需求文档

## 产品定位

基于 ESP32-S3 的 AI 音响音乐播放器，支持本地音乐播放与智能交互。

## 功能需求

### 核心功能
- [ ] 音乐播放控制（播放 / 暂停 / 上一首 / 下一首）
- [ ] 播放模式切换（顺序 / 随机 / 单曲循环 / 列表循环）
- [ ] 音量调节
- [ ] 播放进度显示与拖动

### 页面需求
- [ ] 播放页（Now Playing）
- [ ] 歌单页（Playlist）
- [ ] 电台页（Radio）
- [ ] 搜索页（Search）

### 显示需求
- [ ] 适配 320×240 分辨率屏幕
- [ ] 深色主题 UI
- [ ] 封面、歌曲名、艺术家、专辑信息展示

## 待补充

- 音频解码格式（MP3 / FLAC / AAC ...）
- 存储介质（SD 卡 / SPI Flash / 网络流）
- 音频输出方式（I2S DAC / 功放 / 蓝牙）
- 交互方式（触摸屏 / 按键 / 语音）
