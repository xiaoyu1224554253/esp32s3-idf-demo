# 灵镜 AI 音响 — 需求文档

## 产品定位

基于 ESP32-S3 + ES3C28P 开发板的 AI 音响音乐播放器，支持本地音乐播放与智能交互。

## 硬件平台

- **开发板**：LCDWiki ES3C28P（2.8 寸电容触摸屏版本）
- **主控**：ESP32-S3（N16R8：16 MB Flash + 8 MB PSRAM）
- **屏幕**：2.8 寸 IPS TFT，240 × 320，ILI9341V 驱动，4-Line SPI
- **触摸屏**：电容屏，FT6336G 驱动，I2C 接口
- **音频编解码**：ES8311（I2S）
- **音频功放**：FM8002E
- **存储**：MicroSD 卡（SDIO）
- **麦克风**：LMA2718B381-OA7（支持 AI 语音交互扩展）

## 功能需求

### 核心播放功能
- [ ] 音乐播放控制（播放 / 暂停 / 上一首 / 下一首）
- [ ] 播放模式切换（顺序 / 随机 / 单曲循环 / 列表循环）
- [ ] 音量调节（0 ~ 100）
- [ ] 播放进度显示与拖动
- [ ] 支持从 MicroSD 卡读取音频文件

### 页面需求
- [ ] 播放页（Now Playing）
- [ ] 歌单页（Playlist）
- [ ] 电台页（Radio）
- [ ] 搜索页（Search）

### 显示与交互需求
- [ ] 适配 240 × 320 竖屏分辨率
- [ ] 深色主题 UI
- [ ] 封面、歌曲名、艺术家、专辑信息展示
- [ ] 电容触摸屏手势/点击交互

### 音频需求
- [ ] 通过 ES8311 + FM8002E 驱动喇叭输出
- [ ] 优先支持 MP3 格式解码
- [ ] 支持播放 / 暂停 / 切歌时音频流畅切换
