# 灵镜 AI 音响音乐播放器 — 集成测试清单

## 环境准备

- ESP32-S3 ES3C28P 开发板
- MicroSD 卡（FAT32），根目录放置若干 MP3 文件
- USB Type-C 供电/串口

## 测试项

### 1. 启动与显示
- [ ] 上电后屏幕点亮，背光正常
- [ ] 显示深色主题的 "Now Playing" 页面
- [ ] 标题、艺术家、进度条、时间、控制按钮显示正常

### 2. 触摸交互
- [ ] 点击 Play 按钮开始播放
- [ ] 点击 Pause 按钮暂停播放
- [ ] 点击 Next 按钮切换到下一首
- [ ] 点击 Prev 按钮切换到上一首
- [ ] 点击 List 按钮进入歌单页
- [ ] 在歌单页点击歌曲可播放并返回播放页
- [ ] 点击 Radio 按钮进入电台页

### 3. 音频播放
- [ ] 喇叭输出 MP3 音频
- [ ] 音量默认 50%，无明显失真
- [ ] 切歌时音频流畅切换

### 4. 播放模式
- [ ] 顺序播放模式正常工作
- [ ] 随机播放模式可随机切换歌曲
- [ ] 单曲循环模式重复播放同一首
- [ ] 列表循环模式播完最后一首后回到第一首

### 5. 稳定性
- [ ] 连续播放 30 分钟无崩溃
- [ ] 插拔 SD 卡后系统不崩溃（可提示未挂载）

## 已知限制

- 进度拖动尚未实现
- 歌词显示尚未实现
- 封面图片显示尚未实现
- 网络电台为占位页面
