# 灵镜 AI 音响音乐播放器 UI 原型设计

## 目标
为 LCDWiki ES3C28P（ESP32-S3 + ILI9341 320×240 横屏 + FT6336 电容触摸）开发板，制作一个可在浏览器中 1:1 预览和调试的音乐播放器 UI 原型。

## 范围
- 仅实现 UI 和前端交互，不播放真实音频
- 4 个页面：播放、歌单、电台、搜索
- 所有可点击区域 ≥36×36 像素
- 后期将基于该原型移植为 LVGL + ESP32 实现

## 设计决策
1. **单文件 HTML**：零依赖，双击打开即可预览
2. **320×240 画布**：按开发板屏幕 1:1 设计，外围自动放大居中
3. **深色主题 + 紫蓝渐变**：还原截图风格
4. **模块化 JS 结构**：页面、状态、事件分离，便于后续对应 LVGL 架构

## 页面结构
### 播放页
- 顶部状态栏：时间、WiFi、电量
- 专辑封面 + 歌曲信息
- 歌词区（5 行，当前句高亮）
- 进度条 + 时间
- 播放控制：上一首、播放/暂停、下一首
- 底部导航栏

### 歌单页
- 标题 + 来源标识
- 播放模式：顺序/随机/单曲循环
- 歌曲列表（带序号、来源图标）

### 电台页
- 分类标签：全部/流行/古典/爵士/电子/民谣/新闻
- 正在播放卡片
- 电台列表

### 搜索页
- 搜索框 + 语音按钮
- 搜索历史
- 搜索结果

## 技术方案
- HTML5 + CSS3 + 原生 JavaScript
- CSS 变量管理主题色
- 状态对象：`{ page, isPlaying, currentSong, progress, playlist, ... }`
- 页面切换通过显示/隐藏对应 DOM 实现

## 后续移植到 ESP32
- HTML 中的页面函数对应 LVGL 的 `lv_obj_t *screen_xxx`
- 状态对象对应 LVGL 的全局状态结构体
- CSS 变量对应 LVGL 颜色宏
- 触摸事件对应 FT6336 的触摸回调

## 验收标准
- [ ] 浏览器中 320×240 画布 1:1 显示
- [ ] 4 个页面可通过底部导航切换
- [ ] 播放/暂停按钮可切换状态
- [ ] 进度条可拖动
- [ ] 所有可点击区域 ≥36×36 像素
- [ ] 视觉风格与截图一致
